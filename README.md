# 식물환자 (PlantChart)

작물이 스트레스를 받을 때 내는 초음파를 감지해, 육안 증상이 나타나기 전에 농가에 알려주는 조기경보 서비스 프로토타입입니다.

**2026 연암SMART팜 융복합 공모전 출품작**

## 데모

https://a01023133028-alt.github.io/plant-patient/

휴대폰 브라우저로 열어보는 것을 권장합니다.

## 핵심 컨셉

작물을 환자처럼 진료합니다. 베드 번호를 병상 번호처럼 쓰고, 개체별 진료 차트를 만들고,
AI가 진단 소견과 권장 조치를 내놓습니다.

| 화면 | 내용 |
|---|---|
| 병동 | 전체 개체 상태 요약, 위험 개체가 항상 맨 위 |
| 알림 | 카카오톡 알림톡 + 앱 푸시 기록 |
| 진료 차트 | 7일 초음파 추세, AI 진단 소견, 권장 조치, 진료 기록 |
| 설정 | 알림 대상, 위험 기준값, 알림 시간대, 시연 모드 |

## 발표 시연

설정 탭 맨 아래 **"시연 모드: 이상 신호 발생시키기"** 버튼을 누르면 약 3초에 걸쳐
B-2 파프리카가 정상 → 주의 → 위험으로 바뀌고, 추세 그래프가 치솟고, 푸시 배너가 내려오고,
알림 탭에 뱃지가 붙습니다. **"초기화"** 로 되돌릴 수 있습니다.

## 근거

- 식물은 스트레스를 받으면 **40~80kHz** 초음파를 방출합니다. 스트레스 상태에서 시간당 30~50회,
  정상일 때는 거의 발생하지 않습니다.
- 사람의 가청 한계는 20kHz라 맨귀로는 들을 수 없습니다.
- 육안 시듦 증상보다 **2~3일 먼저** 소리가 발생합니다.
- 공개 데이터 5,477건을 자체 재분석한 결과, 식물 소리는 20kHz 미만 성분이 0.2%인 반면
  온실 배경소음은 18.6%였습니다. 대역 필터만으로 1차 분리가 가능합니다.

> Khait et al., *Cell* (2023) — "Sounds emitted by plants under stress are airborne and informative"

## 기술

`index.html` 단일 파일입니다. 빌드 도구, 프레임워크, 외부 라이브러리, 백엔드가 없습니다.
차트는 인라인 SVG로 직접 그렸고, 상태는 자바스크립트 변수로만 관리합니다.
화면의 계측값은 시연용 예시 데이터입니다.
