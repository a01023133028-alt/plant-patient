# 식물환자 관수 시뮬레이터

관수량을 줄이면 당도는 오르고 수량은 줄어드는 관계를 슬라이더로 직접 체험하는 웹 페이지입니다.
2026 연암SMART팜 융복합 공모전 본선 발표 시연용입니다.

> 이 시뮬레이터는 공개 연구 수치에 맞춘 교육용 모델입니다. 실제 재배 결과가 아니며, 파일럿 실험으로 검증할 예정입니다.

## 실행 방법

- **화면**: `index.html`을 더블클릭하면 크롬·엣지에서 바로 열립니다. 인터넷 연결이나 외부 라이브러리가 필요 없습니다.
  `index.html` 안에 계산 로직이 들어 있어서 **이 파일 하나만 옮겨도** 열립니다.
- **계산 로직을 고쳤을 때**: `model.js`를 고친 뒤 `node build.js`를 실행하면 `index.html` 안의 로직이 갱신됩니다. `node test.js`가 둘이 같은지 확인합니다.
- **검증**: `node test.js` (Node.js 필요). 11개 항목, 42개 세부 검사를 자동으로 확인하고 통과/실패를 출력합니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 (조작 패널, 온실 SVG, 그래프, 결과 카드, 세 방식 비교, 가정·근거 패널) |
| `model.js` | 계산 로직. 브라우저에서는 `window.PlantModel`, Node에서는 `module.exports` |
| `test.js` | 모델 검증 |
| `build.js` | `model.js`를 `index.html` 안에 복사 (한 파일로 열리게) |

화면 오른쪽 맨 위의 **"관수량과 당도의 관계"** 그래프가 핵심입니다. 관수 비율 40~110%마다 재배 기간이 끝났을 때의 당도를 계산해 곡선으로 그립니다(보통·폭염 두 곡선). 점은 지금 설정입니다.

## 발표 시연 순서

1. **① 충분히 관수** 선택 → ⏭ 결과 바로 보기. 당도 5.0 Brix, 클릭은 시간당 1회 미만으로 조용합니다.
2. **② 고정 감량** 선택 → 슬라이더를 **70%**로: 관계 그래프의 점이 왼쪽 위로 이동하며 당도 +0.7, 수량 −8%. 이어서 **50%**로: 당도 +1.0, 수량 −12%. 클릭이 경보선(15)을 넘기 시작하고 잎이 처집니다.
   - 말할 점: 물만 줄여서는 고당도 기준(8 Brix)에 못 미칩니다. 대저 짭짤이처럼 8 Brix를 넘기려면 염류 같은 다른 조건이 필요합니다.
3. **폭염** 켜기 → 관계 그래프의 곡선이 위로 올라갑니다(같은 물에서도 스트레스가 더 큼). 50%에서 수량이 −14%로 더 줄고, 경보가 뜨면 화면 테두리가 빨갛게 깜빡입니다.
4. **③ 소리 브레이크** 선택 → ▶ 재생. 하루 10%p씩 줄이다가 클릭이 대조 구역보다 늘면 "멈춤 (소리 증가)"로 바뀌고 한 계단 복귀합니다. "클릭 소리 듣기"를 켜면 예시음이 들립니다.
5. **📊 세 방식 한 번에 비교** → 같은 조건의 3그룹(100% / 70% 고정 / 소리 브레이크)의 당도·수량·물 사용량을 막대그래프와 표로 비교. CSV·PNG로 저장해 슬라이드에 붙입니다.

## 계산 규칙 (하루 단위)

1. **스트레스 S (0~1)**: 부족분 `d = max(0, 1 − 관수비율)`, 폭염이면 `d × 1.4 + 0.05`.
   `S += 축적 × d × (1 − S) − 회복 × (1 − d) × S`
2. **당도**: `5 + 1.22 × (1 − e^(−x/8))`. `x`는 S ≥ 0.15가 3일 이상 연속된 날의 `(S − 0.15)` 누적. 짧은 스트레스는 당도를 거의 못 올립니다.
3. **수량**: 매일 `1 − 0.193·S − b·max(0, S − 0.45)²`, 기간 평균 (토마토는 b = 0, 다른 작물은 2.5).
4. **클릭**: `0.5 + 45 × S² × 피로 × (1 + 노이즈)`. 피로는 S ≥ 0.8인 날이 2일을 넘으면 `e^(−초과일/3)`로 줄어 최고점 이후 감소(비단조)를 재현합니다. 노이즈는 시드 고정 난수(mulberry32).
5. **물 사용량**: 관수 비율의 누적 평균 (100% 관수 대비).
6. **소리 브레이크**: 100%에서 시작해 하루 10%p씩 감량. 같은 날씨의 대조 구역(100%) 클릭을 함께 계산하고,
   전날 클릭이 대조보다 4회/시간 이상 많으면 감량을 멈추고 한 계단 복귀 후 유지(이틀 연속 여전히 높으면 한 계단 더 복귀).
   클릭이 경보 기준(15)을 넘으면 **그날 바로 100%**로 바꾸고 경보를 기록, 3일 유지 후 다시 감량합니다.

## 프롬프트 대비 조정한 점과 이유

- **기본 토마토를 Plants (2024) 원문 기준으로 바꿈**: 처음 프롬프트는 "70% 관수 → 수량 −12%, 당도 +1.5 이상"을 요구했지만, 원문을 확인해 보니 −12%는 **물 47%** 조건이었고 통계적으로 유의하지 않았습니다. 그래서 검사 2·3번을 원문 기준으로 바꿨습니다.
  - 검사 2: 70% → 수량 −3~−10%, 당도 +0.4 이상 (전: 수량 −8~−16%, 당도 +1.5 이상)
  - 검사 3: 물 47% → 수량 −5~−15%, 당도 +0.6~1.3 (전: 50% → 수량 −20% 이하)
  - 처음 설정은 작물 목록의 "토마토 (처음 초안)"으로 남겨 두었습니다.

아래 두 가지는 프롬프트의 예시 식에서 바꾼 부분입니다.

- **스트레스 식에 `(1 − S)`, `S`를 곱함**: 예시 식 `S += 축적 × d − 회복 × (1 − d)`은 균형점이 없어서, 70%든 50%든 조금만 지나면 S가 1에 붙어 두 경우의 수량·당도가 같아집니다.
  곱셈 항을 넣어 관수 비율마다 S가 일정 수준으로 수렴하게 했습니다 (70% → 약 0.42, 50% → 약 0.63, 100% → 0).
- **폭염 기본 부족분 0.05 추가**: 부족분에 가중치만 곱하면 100% 관수에서는 폭염 효과가 0이 됩니다. 증산이 늘어 100%에서도 약간 부족해진다는 가정을 넣었습니다.

### 원문을 확인하고 알게 된 점

- **Plants (2024)**: 프롬프트의 "−12~13%, −24%"는 실제 논문 수치가 맞지만, 물을 대조구의 **47%·13%·15%**만 준 조건이었고 **통계적으로 유의하지 않은** 감소였습니다. 그래서 원문에 맞춘 "토마토 (논문 기준)"을 발표 기본값으로 쓰고, 처음 설정은 "토마토 (처음 초안)"으로 남겼습니다.
- **Cell (2023)**: 건조 토마토 35.4±6.1회/시간, 담배 11.0±1.4회/시간, 대조군 1회 미만, 물을 준 뒤 4~5일 증가 후 감소를 원문에서 확인했습니다. 딸기·멜론·감귤·파프리카의 소리는 **측정 자료가 없어** 토마토 값을 그대로 씁니다(가정).
- **멜론**: 연구 조건은 70%가 아니라 **50% ETc**였습니다.
- **딸기**: 정식 직후부터 물을 줄이면 환원당이 −25.1%로 **오히려 줄었다**는 국내 연구가 있어, 당도 상승을 아주 작게 잡았습니다.
- **감귤**: 피복 후 **30~60일 지나야** 건조 스트레스가 시작된다는 내용이 모델의 "지속될 때만 당도 상승" 가정을 뒷받침합니다. 재배 기간을 60일로 늘려 보세요.
- 일반 당도·고당도 기준 중 출처가 없는 값(방울토마토 7, 딸기 9, 멜론 11, 파프리카 7 등)은 **가정**으로 표시했습니다.

관수를 줄일수록 당도는 오르고 수량은 줄어듭니다. 다만 원문 기준으로는 그 폭이 크지 않습니다(70%에서 당도 +0.7, 수량 −8%). 소리 브레이크는 당도 상승이 작은 대신 수량을 지키고, 폭염에서도 경보가 없습니다.
